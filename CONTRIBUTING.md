# Contributing

Thanks for your interest in contributing. To keep reviews quick and the history easy to follow, please:

1. **Keep changes focused.** Open one pull request per logical change, and describe what it does and why in the PR description.
2. **Check your work before opening a PR.** Run the existing tests and linters, and add or update tests for any behaviour you change.
3. **Be respectful in discussions.** Give constructive feedback on code rather than on people, and be open to review comments.
