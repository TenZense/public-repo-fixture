# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Discussing the approach up front avoids wasted effort and helps keep changes focused.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests where it makes sense, and update documentation that your change affects.
