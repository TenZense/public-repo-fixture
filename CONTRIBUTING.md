# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the problem or proposal so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single change, include a clear description, and pass any existing tests.
3. **Follow the existing style.** Match the formatting and conventions already used in the codebase, and write clear commit messages.
