# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue to discuss the change before starting work so we can agree on the approach.
2. **Keep pull requests focused.** Each PR should address a single concern, include a clear description of what changed and why, and add or update tests where relevant.
3. **Follow the existing style.** Match the formatting, naming, and structure already used in the codebase, and make sure the project builds and all checks pass before requesting review.
