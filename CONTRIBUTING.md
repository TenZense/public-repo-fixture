# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so we can agree on the approach.
2. **Keep pull requests small and focused.** Each PR should address a single concern, include a clear description, and reference any related issues.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase and include tests or examples for new behaviour where applicable.
