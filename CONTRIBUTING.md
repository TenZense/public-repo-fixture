# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For significant changes, describe the problem or proposal before writing code so we can agree on the approach.
2. **Keep changes focused.** Submit small, well-scoped pull requests with clear commit messages and tests where applicable.
3. **Be respectful.** Review others' work constructively and respond to feedback promptly and courteously.
