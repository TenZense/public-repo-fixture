# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Describe the problem and your proposed approach so it can be discussed before you invest time in a pull request.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Write clear commit messages and test your changes.** Use a concise summary line, explain the reasoning in the body where useful, and verify that your change works before requesting review.
