# Contributing

Thanks for your interest in contributing. Please keep the following in mind:

1. **Keep changes focused.** Make one logical change per pull request, and describe clearly what it does and why.
2. **Write clear commit messages.** Use a short summary line, followed by a body explaining the reasoning when it isn't obvious from the diff.
3. **Check your work before opening a pull request.** Confirm the affected files render or run as expected, and make sure your change doesn't add unrelated edits or files.
