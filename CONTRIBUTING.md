# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make each pull request address one issue or one logical change, and describe what it does and why in the PR description.
2. **Test your changes.** Run the existing tests and checks before opening a pull request, and add tests for new behaviour where practical.
3. **Be respectful in discussions.** Give constructive feedback on code and ideas, and assume good intent from other contributors.
