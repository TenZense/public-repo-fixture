# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make each pull request address one clear problem or feature, and describe what it changes and why in the PR description.
2. **Test your changes.** Run the existing checks or tests before opening a pull request, and add tests for new behaviour where practical.
3. **Be respectful in discussions.** Give constructive feedback on code and proposals, and be open to review comments.
