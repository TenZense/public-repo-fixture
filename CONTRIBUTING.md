# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the proposed change so we can agree on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description, and add or update tests where applicable.
3. **Follow the existing style.** Match the formatting and conventions already used in the codebase, and make sure all checks pass before requesting review.
