# Contributing

Thanks for your interest in contributing! Please follow these guidelines when opening issues or pull requests.

1. **Keep changes focused.** Make each pull request address a single concern, and keep unrelated refactors or formatting changes in separate pull requests.
2. **Describe what and why.** Explain the purpose of your change and how it was verified in the pull request description, so reviewers can evaluate it quickly.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review comments.
