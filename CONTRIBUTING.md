# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting work on a significant change, open an issue to discuss it so we can agree on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description of the change, and keep the diff as small as practical.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase, and include or update tests where applicable so changes stay verifiable.
