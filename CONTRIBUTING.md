# Contributing

Thank you for your interest in contributing to this project. Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so maintainers can provide feedback early.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description of the change, and add or update tests where applicable.
3. **Follow the existing style.** Match the formatting, naming conventions, and structure already used in the codebase, and make sure any existing checks pass before requesting review.
