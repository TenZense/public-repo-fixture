# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind when submitting changes.

1. **Keep changes focused.** Each pull request should address a single change or topic, and should include a clear description of what changed and why.
2. **Test your changes.** Run the existing test suite and add tests for new behaviour or bug fixes before requesting review.
3. **Be respectful in discussions.** Give constructive, specific feedback on code and proposals, and assume good intent from other contributors.
