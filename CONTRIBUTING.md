# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Describe the problem or proposal so it can be discussed before you invest time in an implementation.
2. **Keep pull requests small and focused.** Each pull request should address a single concern and include a clear description of what changed and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests where it makes sense, and update the documentation for any behaviour you change.
