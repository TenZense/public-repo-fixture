# Contributing

Thanks for your interest in contributing! Please follow these guidelines to keep contributions smooth and consistent.

1. **Open an issue first for larger changes.** Before starting significant work, open an issue describing the problem and your proposed approach so it can be discussed and agreed upon.

2. **Keep pull requests small and focused.** Each pull request should address a single concern, include a clear description of what changed and why, and add or update tests where applicable.

3. **Follow the existing code style and conventions.** Match the formatting, naming, and structure already used in the repository, and make sure any linters or test suites pass before requesting a review.
