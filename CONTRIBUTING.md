# Contributing

Thanks for your interest in contributing! Please follow these guidelines when opening issues or pull requests.

1. **Keep changes focused.** Make each pull request address a single concern, and describe what it changes and why in the PR description.
2. **Check before you submit.** Run the project's existing tests and linters, and confirm your change builds cleanly before requesting a review.
3. **Be respectful in discussions.** Give constructive, specific feedback on code and proposals, and assume good intent from other contributors.
