# Contributing

Thanks for your interest in contributing! To keep things smooth for everyone:

1. **Discuss larger changes first.** Open an issue to describe a proposed change before starting significant work, so effort is aligned with the project's direction.
2. **Keep changes focused.** Submit one logical change per pull request, with a clear description of what changed and why.
3. **Follow the existing style and test your changes.** Match the conventions already used in the codebase and verify your change works before requesting review.
