# Contributing

Thanks for your interest in contributing! Please follow these guidelines.

1. **Keep changes focused.** Make each pull request address a single issue or feature, and keep the diff small enough to review easily.
2. **Write clear commit messages.** Describe what changed and why, using the imperative mood (e.g. "Fix typo in README").
3. **Test and document your work.** Make sure existing tests pass, add tests for new behavior, and update documentation where relevant.
