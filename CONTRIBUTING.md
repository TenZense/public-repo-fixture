# Contributing

Thank you for your interest in contributing to this project. Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the change you'd like to make so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern and include a clear description of what changed and why.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase, and include tests for new or changed behaviour where applicable.
