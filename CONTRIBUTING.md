# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, describe the change you'd like to make so it can be discussed before you invest time in it.
2. **Keep pull requests focused.** One logical change per pull request, with a clear description of what changed and why.
3. **Be respectful.** Treat maintainers and other contributors with courtesy, and respond constructively to review feedback.
