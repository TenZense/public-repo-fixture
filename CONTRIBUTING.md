# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Discuss larger features or behavioural changes before starting work so effort isn't wasted.
2. **Keep pull requests small and focused.** One logical change per PR, with a clear description of what it does and why.
3. **Write clear commit messages and include tests where applicable.** Make sure existing tests pass before requesting review.
