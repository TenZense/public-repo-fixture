# Contributing

Thanks for your interest in contributing! To keep changes easy to review, please:

1. **Open an issue or discussion first** for larger changes, so the approach can be agreed before significant work begins.
2. **Keep pull requests focused.** One logical change per PR, with a clear description of what changed and why.
3. **Write clear commit messages** that summarize the change in the first line and explain the reasoning in the body when it isn't obvious.
