# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for larger changes.** Discuss significant changes before starting work so effort isn't duplicated or wasted.
2. **Keep pull requests small and focused.** One logical change per PR, with a clear description of what it does and why.
3. **Be respectful and constructive.** Review feedback is about the code, not the person — assume good intent and keep discussions courteous.
