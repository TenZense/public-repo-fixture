# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach before investing significant time, so we can agree on direction early.
2. **Keep pull requests small and focused.** Each PR should address a single concern, with a clear description of what changed and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests for new behaviour where practical, and update any relevant documentation.
