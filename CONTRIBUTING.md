# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Discuss larger features or behavioural changes before starting work so effort isn't duplicated or wasted.
2. **Keep pull requests small and focused.** Each PR should address a single concern, include a clear description of what changed and why, and update documentation where relevant.
3. **Test your changes and follow existing style.** Make sure existing tests pass, add tests for new behaviour where practical, and match the conventions already used in the codebase.
