# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make each pull request address a single problem or feature, and describe what changed and why in the PR description.
2. **Check your work before opening a PR.** Run the relevant tests or checks locally and confirm the change behaves as described.
3. **Be respectful in reviews.** Give specific, constructive feedback, and be open to suggestions on your own changes.
