# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Each pull request should address one clear purpose. Split unrelated changes into separate pull requests.
2. **Describe what and why.** Explain the problem your change solves and how you verified it in the pull request description.
3. **Be respectful in discussion.** Give constructive feedback, assume good intent, and be open to revising your work based on review.
