# Contributing

Thanks for your interest in contributing. Please follow these guidelines when opening issues or pull requests:

1. **Keep changes focused.** Each pull request should address a single change or problem, and include a clear description of what it does and why.
2. **Test your changes.** Confirm that your change works as expected and that existing tests still pass before requesting a review.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and keep reviews centred on the code.
