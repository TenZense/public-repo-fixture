# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make one logical change per pull request, and describe it clearly in the PR description.
2. **Test your changes.** Run the existing tests and linters before opening a pull request, and add tests for new behaviour where practical.
3. **Be respectful in discussions.** Give feedback on the code rather than the author, and be open to revising your approach based on review.
