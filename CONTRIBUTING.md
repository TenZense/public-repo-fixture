# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, open an issue describing the change so it can be discussed before you invest time in a pull request.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Test your changes.** Make sure existing tests pass and add tests or documentation updates where appropriate.
