# Contributing

Thanks for your interest in contributing. To keep changes easy to review:

1. **Keep changes focused.** Make each pull request address one clear problem or improvement, and describe what changed and why in the PR description.
2. **Test your changes.** Run the project's existing tests and checks before opening a pull request, and add or update tests when behaviour changes.
3. **Be respectful and constructive.** Write clear, specific review comments and be open to feedback on your own work.
