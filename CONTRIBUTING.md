# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind.

## Guidelines

1. **Open an issue first for significant changes.** Describe the problem or proposal so it can be discussed before you invest time in an implementation. Small fixes (typos, minor bugs) can go straight to a pull request.

2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear title and a description explaining what changed and why.

3. **Write clear commit messages and verify your changes.** Use a concise summary line, add detail in the body where useful, and make sure existing checks pass (and add tests where applicable) before requesting review.
