# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address one thing, and keep unrelated refactors or formatting changes in separate pull requests.
2. **Describe your change.** Explain what the change does and why it is needed in the pull request description, and note how you verified it.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review comments.
