# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Discussing the idea up front helps avoid duplicated or wasted effort.
2. **Keep pull requests small and focused.** Each PR should address a single concern and include a clear description of what changed and why.
3. **Follow the existing style and test your changes.** Match the conventions already used in the project and make sure everything works before requesting review.
