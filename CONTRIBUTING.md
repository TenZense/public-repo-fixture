# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address one issue or one logical change, and describe what it does and why in the pull request description.
2. **Check before you submit.** Run the project's tests and linters locally, and confirm your change does what you intended before requesting review.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review comments.
