# Contributing

Thanks for your interest in contributing. To keep reviews quick and the history clear, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address one topic, and keep unrelated refactors or formatting changes in separate pull requests.
2. **Describe your change.** Explain what changed and why in the pull request description, and note how you tested it.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review comments.
