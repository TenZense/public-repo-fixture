# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Describe the problem and your proposed approach so it can be discussed before you invest time in a pull request.
2. **Keep pull requests small and focused.** Each PR should address a single concern, with a clear description of what changed and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests for new behaviour where applicable, and update the documentation to match.
