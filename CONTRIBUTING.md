# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address a single problem or feature, and describe what it changes and why in the PR description.
2. **Check your work before submitting.** Run the project's tests and linters locally, and make sure your branch is up to date with the default branch before opening a pull request.
3. **Be respectful in discussions.** Give clear, constructive feedback on issues and reviews, and assume good intent from other contributors.
