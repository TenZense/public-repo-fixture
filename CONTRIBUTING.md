# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so we can agree on the approach.
2. **Keep pull requests focused.** Each PR should address a single concern, include a clear description, and pass any existing tests or checks.
3. **Follow the existing style.** Match the formatting and conventions already used in the codebase, and update documentation where your change affects it.
