# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For significant changes, open an issue to discuss what you'd like to change before submitting a pull request.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear description of what it changes and why.
3. **Test your changes.** Make sure existing tests pass and add tests for new behaviour where appropriate.
