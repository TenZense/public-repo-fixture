# Contributing

Thanks for your interest in contributing! Please follow these guidelines to keep contributions easy to review and merge.

1. **Open an issue first for larger changes.** Describe the problem you want to solve and your proposed approach before investing significant effort, so we can agree on direction early.

2. **Keep pull requests small and focused.** Each pull request should address a single concern, include a clear description of what changed and why, and follow the existing style of the codebase.

3. **Be respectful and constructive.** Treat other contributors with courtesy in issues, reviews, and discussions, and keep feedback focused on the work rather than the person.
