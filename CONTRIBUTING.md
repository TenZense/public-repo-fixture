# Contributing

Thank you for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the proposed change so we can align on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description of what changed and why, and keep the diff as small as practical.
3. **Follow existing conventions.** Match the code style, naming, and structure already used in the repository, and make sure any existing tests or checks pass before requesting review.
