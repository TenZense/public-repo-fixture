# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so we can agree on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description, and reference any related issue.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase and include tests or documentation updates for any behaviour you change.
