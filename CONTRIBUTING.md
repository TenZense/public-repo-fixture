# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the change you'd like to make so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern. Include a clear description of what changed and why.
3. **Follow the existing style.** Match the formatting and conventions already used in the codebase, and make sure any tests pass before submitting.
