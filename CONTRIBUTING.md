# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind:

1. **Open an issue first for significant changes.** Describe the problem and your proposed approach so it can be discussed before you invest time in an implementation.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests for new behaviour where practical, and update the documentation when behaviour changes.
