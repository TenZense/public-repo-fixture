# Contributing

Thanks for your interest in contributing. To keep reviews quick and the history easy to follow, please:

1. **Keep changes focused.** Make each pull request address one problem or one feature, and describe what it changes and why.
2. **Test your changes.** Run the existing tests and add new ones where they cover the behaviour you changed before requesting a review.
3. **Be respectful in discussions.** Give feedback on the code rather than the person, and assume good intent from others.
