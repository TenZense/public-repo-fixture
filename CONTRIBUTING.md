# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the proposed change so we can agree on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear title and description of what changed and why.
3. **Follow the existing style and add tests.** Match the conventions already used in the codebase, and include tests or documentation updates where relevant.
