# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach so maintainers can give feedback before you invest significant time.
2. **Keep changes focused.** Each pull request should address one logical change, with a clear description of what it does and why.
3. **Write clear commit messages and test your work.** Use concise, descriptive commit messages and verify your changes before requesting review.
