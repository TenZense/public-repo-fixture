# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please:

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach so maintainers can give feedback before you invest significant effort.
2. **Keep each pull request focused.** Make one logical change per PR, include a clear description of what changed and why, and make sure existing checks pass.
3. **Be respectful and constructive in discussions.** Assume good intent, address the code rather than the person, and be responsive to review feedback.
