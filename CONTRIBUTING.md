# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Discuss larger features or behavior changes before starting work so effort isn't duplicated or wasted.
2. **Keep pull requests small and focused.** Each PR should address a single concern, with a clear description of what changed and why.
3. **Be respectful and constructive.** Review feedback is about the code, not the person. Assume good intent and keep discussions professional.
