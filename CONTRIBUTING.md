# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please follow these guidelines:

1. **Keep changes focused.** Make each pull request address one logical change, and describe what it does and why in the PR description.
2. **Match the existing style.** Follow the conventions already used in the code and documentation, and run any available linters or tests before opening a pull request.
3. **Be respectful in discussions.** Give constructive feedback, assume good intent, and be open to revising your work based on review comments.
