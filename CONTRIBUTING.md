# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach before investing significant effort, so we can discuss it early.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description of what changed and why, and update documentation where relevant.
3. **Be respectful and constructive.** Treat all participants with courtesy in issues, reviews, and discussions.
