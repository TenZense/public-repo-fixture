# Contributing

Thanks for your interest in contributing. Please follow these guidelines when opening changes:

1. **Keep changes focused.** Each pull request should address one logical change, with a clear description of what it does and why.
2. **Test your changes.** Run the existing tests and checks before requesting review, and add tests for new behaviour where practical.
3. **Communicate early.** For larger changes, open an issue to discuss the approach before writing significant code.
