# Contributing

Thanks for your interest in contributing. To keep changes easy to review, please:

1. **Keep changes focused.** Make each pull request address a single problem or feature, and describe what it changes and why.
2. **Test your changes.** Run the existing checks, and add or update tests where your change affects behaviour.
3. **Be respectful in discussions.** Give constructive feedback on code, not on people, and assume good intent from others.
