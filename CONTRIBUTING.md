# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Describe the problem and your proposed approach before investing time in a large pull request, so we can agree on direction early.
2. **Keep pull requests small and focused.** One logical change per PR, with a clear title and description explaining what changed and why.
3. **Follow the existing code style and add tests.** Match the conventions already used in the repository, and include tests or documentation updates for any behavior you change.
