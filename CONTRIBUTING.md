# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for significant changes.** Describe the problem and your proposed approach before investing time in a large pull request.
2. **Keep pull requests small and focused.** Each pull request should address one change, with a clear description of what it does and why.
3. **Test and document your changes.** Make sure existing checks pass, add tests where it makes sense, and update the documentation to match.
