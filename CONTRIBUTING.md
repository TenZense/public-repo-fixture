# Contributing

Thanks for your interest in contributing! Please follow these guidelines when opening changes:

1. **Keep changes focused.** Each pull request should address a single bug fix, feature, or cleanup so it is easy to review and revert if needed.
2. **Describe your change.** Explain what changed and why in the pull request description, and link any related issue.
3. **Check your work before submitting.** Run the project's tests and linters locally and make sure they pass.
