# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, describe the problem or proposal before starting work so it can be discussed.
2. **Keep changes focused.** Make small, self-contained pull requests with clear commit messages and a description of what changed and why.
3. **Test your changes.** Make sure existing tests pass and add tests for new behavior before requesting review.
