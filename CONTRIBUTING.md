# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue to discuss the change so we can agree on the approach.
2. **Keep pull requests focused.** Each pull request should address a single concern, with a clear title and description explaining what changed and why.
3. **Test your changes.** Make sure existing tests pass and add new tests where appropriate before submitting your pull request.
