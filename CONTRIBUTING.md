# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind.

1. **Open an issue first for significant changes.** Describe the problem or proposal so it can be discussed before you invest time in an implementation.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Write clear commit messages and test your changes.** Use descriptive commit messages, and make sure existing checks pass before requesting a review.
