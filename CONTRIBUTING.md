# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Discuss the problem and proposed approach before investing time in a large pull request.
2. **Keep pull requests focused.** Each PR should address a single concern, with a clear description of what changed and why.
3. **Write clear commit messages and test your changes.** Make sure existing checks pass and add tests where appropriate before requesting review.
