# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first for significant changes.** Describe the problem or proposal before starting work so the approach can be discussed early.
2. **Keep pull requests small and focused.** Each PR should address a single concern, include a clear description, and pass any existing tests.
3. **Follow the existing code style and conventions.** Match the formatting, naming, and structure already used in the project, and update documentation when behaviour changes.
