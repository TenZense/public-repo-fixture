# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach before investing time in a big pull request, so it can be discussed up front.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Follow the existing style and test your changes.** Match the conventions already used in the project, and make sure everything works before requesting review.
