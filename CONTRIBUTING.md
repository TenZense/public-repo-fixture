# Contributing

Thanks for your interest in contributing! Please keep these guidelines in mind:

1. **Keep changes small and focused.** Each pull request should address a single concern, which makes it easier to review and to revert if needed.
2. **Write clear commit messages and PR descriptions.** Explain what changed and why, so reviewers and future readers can follow the reasoning.
3. **Be respectful and constructive.** Treat other contributors with courtesy in issues, reviews, and discussions.
