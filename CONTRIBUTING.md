# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** Before starting significant work, open an issue describing the problem or proposed change so it can be discussed.
2. **Keep pull requests focused.** Each pull request should address a single concern, include a clear description, and reference any related issue.
3. **Follow existing conventions.** Match the code style, naming, and structure already used in the repository, and make sure any tests pass before submitting.
