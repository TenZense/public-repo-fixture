# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For significant changes, describe the problem or proposal before writing code so we can discuss the approach.
2. **Keep changes focused.** Submit small, well-scoped pull requests with clear commit messages and, where applicable, tests.
3. **Be respectful.** Review feedback constructively and follow the project's code of conduct in all interactions.
