# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind.

1. **Open an issue first for larger changes.** Describe the problem and your proposed approach before investing significant time, so maintainers can give early feedback.
2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear description of what changed and why.
3. **Follow existing style and verify your changes.** Match the conventions already used in the project, and make sure any tests or checks pass before requesting review.
