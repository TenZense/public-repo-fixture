# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind:

1. **Open an issue first for larger changes.** Discuss significant changes or new features in an issue before starting work, so effort is aligned with the project's direction.
2. **Keep changes focused.** Each pull request should address one logical change, with a clear description of what changed and why.
3. **Write clear commit messages and test your changes.** Use concise, descriptive commit messages, and verify your change works before requesting a review.
