# Contributing

Thanks for your interest in contributing! Please keep the following guidelines in mind.

## Guidelines

1. **Open an issue first for significant changes.** Describe the problem or proposal so it can be discussed before you invest time in an implementation. Small fixes (typos, minor bugs) can go straight to a pull request.

2. **Keep pull requests small and focused.** Each pull request should address a single concern, with a clear title and a description of what changed and why. Unrelated changes belong in separate pull requests.

3. **Follow the existing style and verify your changes.** Match the conventions already used in the repository, write clear commit messages, and make sure any tests or checks pass before requesting review.
