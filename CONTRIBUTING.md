# Contributing

Thanks for your interest in contributing! Please follow these guidelines:

1. **Open an issue first.** For anything beyond a small fix, describe the change you have in mind so it can be discussed before you invest time in it.
2. **Keep changes focused.** Submit one logical change per pull request, with a clear description and commit messages that explain the why.
3. **Test your work.** Make sure existing tests pass, add tests for new behavior, and update documentation where relevant.
